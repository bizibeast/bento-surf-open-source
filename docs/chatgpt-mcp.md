# ChatGPT MCP catalog

The configurable instance origin serves a focused catalog at `/chatgpt/mcp`. OAuth and workspace ownership checks are shared with `/mcp`; the full catalog remains available at `/mcp`. The subset covers pages, content, scheduling and Auto-DMs. It excludes commerce and billing actions. Self-hosting does not imply marketplace approval.
